See the draft the way an engine does.

DraftDiff is a companion for League of Legends champion select. A transformer model paired with Monte-Carlo Tree Search evaluates the draft as it unfolds and suggests picks and bans — with the reasoning behind each one. The decision is always yours.

How it works Under the hood

6-layer transformer · ~6.4M parameters · MCTS search · trained on ~26k ranked matches

01 — How it works

From draft state to ranked suggestions.

DraftDiff follows champion select as it happens and turns each draft state into concrete, explained suggestions — in three steps.

01

Champion select opens

When champion select starts, DraftDiff reads the current draft state from the League Client: picks, bans, and whose turn it is. The board updates as the draft unfolds.

02

The engine evaluates

TitanNet — a 6-layer transformer encoder — scores the position, and Monte-Carlo Tree Search plays out likely draft continuations to test how each candidate pick or ban holds up several turns ahead.

03

You decide

DraftDiff shows ranked suggestions with the reasoning behind them. It never picks for you — the final call is always yours. It does not play the game, read game memory, or automate gameplay.

02 — The engine

Small model, real search.

Titan V3.5 is deliberately compact: a ~6.4M-parameter model that runs comfortably on consumer hardware, paired with tree search for lookahead.

TitanNet engine specifications
EngineTitanNet (Titan V3.5)
ArchitectureTransformer encoder · 6 layers
Model widthd_model = 256
Parameters~6.4M
Output headsPolicy (next pick/ban) + value (draft evaluation)
SearchMonte-Carlo Tree Search over draft continuations
Training data~26,000 ranked matches (EUW), via Match-V5
InferenceConsumer CPUs and GPUs
ApplicationDesktop · Python / PyQt6

Policy head

Trained to predict the next pick or ban from ~26,000 ranked drafts, the policy head proposes candidate moves that reflect how real drafts actually unfold.

Value head

The value head scores the overall draft state, giving the engine a consistent way to compare whole positions — not just isolated picks — when ranking a suggestion.

Monte-Carlo Tree Search

MCTS plays out likely continuations of the draft several turns deep, testing each candidate against plausible responses before anything is shown to the player.

How the API is used

  • Read-only match data: League-V4 ladder seeding, Match-V5 IDs, matches and timelines — nothing else
  • Batch dataset builds, separate from the app itself
  • Rate limits respected by the collection pipeline
  • Data used solely to train the draft model

What never happens

  • No real-time Riot API calls during games
  • No per-player profiling, no public player lookups
  • No redistribution or resale of match data
  • No gameplay automation of any kind

Suggestion-only by design. DraftDiff suggests picks and bans during champion select and explains its reasoning — the player always makes the final call. It does not play the game, does not read game memory, and does not automate gameplay.

Reviewing a Riot Developer Portal application?

The endpoint table above is the complete scope of DraftDiff's Riot API usage. Match data collected through the API is used exclusively to build the training dataset for the draft model — it is never redistributed, resold, or exposed through player lookups, and no Riot API calls are made during live games.

05 — FAQ

Honest answers to fair questions.

Is this allowed by Riot Games?

DraftDiff sits in the established category of champion-select assistance tools: it works with the draft phase only and makes suggestions — it never touches a live game, never reads game memory, and never automates gameplay. This page documents the project's Riot API usage in full, and the complete required disclaimer appears in the footer. DraftDiff is not endorsed by Riot Games.

Does it play the game for me?

No. DraftDiff suggests picks and bans during champion select and explains its reasoning — the decision is always yours. It does not play the game, does not read game memory, and does not automate gameplay.

When can I use it?

DraftDiff is in active development and not yet publicly available. There is no waitlist — release details will be announced on this page when the product is ready.

Where does the draft knowledge come from?

From a model trained on ~26,000 ranked matches collected through the Riot Games API (Match-V5 and League-V4, as documented above). The data is used solely for training and is never redistributed.
