01 How it works

From draft state to ranked suggestions.

Pyxle follows champion select as it happens and turns each draft state into concrete, explained suggestions — in three steps.

01

Champion select opens

When champion select starts, Pyxle reads the current draft state from the League Client: picks, bans, and whose turn it is. The board updates as the draft unfolds.

02

It evaluates the draft

Pyxle scores the current position and plays out likely continuations of the draft, testing how each candidate pick or ban holds up several turns ahead.

03

You decide

Pyxle shows ranked suggestions with the reasoning behind them. It never picks for you — the final call is always yours. It does not play the game, read game memory, or automate gameplay.

02 What it weighs

It reads the whole board, not just one pick.

Pyxle looks at how the five picks fit together and how they stand against the enemy — then explains why each suggestion makes sense right now.

A

Team composition

It weighs how the picks fit together — damage balance, engage, and front-to-back potential — and flags where a composition is becoming one-dimensional.

B

Matchups & counters

It considers how a pick fares into what the enemy has already shown, and what they are likely to pick or ban next.

C

Draft timing

It reads pick and ban order: what is safe to show now, what is worth saving, and how a choice holds up as the remaining slots fill in.

Endpoints used — the complete list

EndpointWhat it returnsWhen it is called

How the API is used

  • Read-only match data: League-V4 ladder seeding, Match-V5 IDs, matches and timelines — nothing else
  • Batch dataset builds, separate from the app itself
  • Rate limits respected by the collection pipeline
  • Data used solely to train the draft model

What never happens

  • No real-time Riot API calls during games
  • No per-player profiling, no public player lookups
  • No redistribution or resale of match data
  • No gameplay automation of any kind

Suggestion-only by design. Pyxle suggests picks and bans during champion select and explains its reasoning — the player always makes the final call. It does not play the game, does not read game memory, and does not automate gameplay.

Reviewing a Riot Developer Portal application?

The endpoint table above is the complete scope of Pyxle's Riot API usage. Match data collected through the API is used exclusively to build the training dataset for the draft model — it is never redistributed, resold, or exposed through player lookups, and no Riot API calls are made during live games.

05 FAQ

Honest answers to fair questions.

Is this allowed by Riot Games?

Pyxle sits in the established category of champion-select assistance tools: it works with the draft phase only and makes suggestions — it never touches a live game, never reads game memory, and never automates gameplay. This page documents the project's Riot API usage in full, and the complete required disclaimer appears in the footer. Pyxle is not endorsed by Riot Games.

Does it play the game for me?

No. Pyxle suggests picks and bans during champion select and explains its reasoning — the decision is always yours. It does not play the game, does not read game memory, and does not automate gameplay.

When can I use it?

Pyxle is in active development and not yet publicly available. There is no waitlist — release details will be announced on this page when the product is ready.

Where does the draft knowledge come from?

From a model trained on ~26,000 ranked matches collected through the Riot Games API (the endpoints listed above). The data is used solely for training and is never redistributed.
